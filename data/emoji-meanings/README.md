# 🫪 Emoji meanings 📚🧩🌈

🧠 Each symbol has one literal Unicode core meaning and a short list of associations.
Associations help initialize embeddings. They do not replace the core definition.
😋 means **face savoring food**; “yum,” “delicious,” and “taste” are related concepts. 🍽️😋✨

🤖 The map covers 3,951 symbols. Start/end protocol controls are excluded.
Skin-tone variants retain their own literal names and inherit associations from
their shared base concept. GPT-5.4 mini generates associations and audits them
in separate requests. No new question–answer examples are generated. 📚🔍✅

🚧 The audit is automated, not independent human verification. It can remove useful
associations: 88 symbols retain only their literal core meaning. Frozen embeddings
prevent vocabulary drift, but do not guarantee that a learned emoji sequence has
a clear human interpretation. That requires separate evaluation. 🧪🧠🫪

💾 `map.json` is the finalized asset. Generation does not repeat when it exists.
`report.json` records its hash, source hash, model, and estimated token cost.
`batches/` preserves generation, review, and invalid review attempts for auditing. 🔍💸📚
